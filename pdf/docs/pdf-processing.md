# PDF 处理说明

## 处理模型

所有文件由用户通过浏览器文件选择、拖拽或受支持的剪贴板能力提供。处理流程为：

```text
选择本地文件
→ 校验类型与文件头
→ 在浏览器内解析
→ 生成低分辨率预览
→ 应用用户参数
→ 在内存中生成新文件
→ 通过 Blob/Object URL 下载
→ 释放临时资源
```

站点不修改磁盘上的原始文件。下载结果是新的 PDF、图片或 ZIP。

## 输入校验

PDF 不能只按扩展名判断，至少需要依次检查：

1. 文件名扩展名为 `.pdf`；
2. MIME 为空或为 `application/pdf`；
3. 文件头以 `%PDF-` 开始；
4. PDF.js 或 `pdf-lib` 能够实际解析；
5. 加密、损坏和不支持的结构映射为明确错误。

图片转 PDF 首期只接受 JPEG、PNG 和 WebP。浏览器实际解码失败时，应保留其他有效文件并指出异常项，不宣称支持未经验证的 HEIC 或 TIFF。

输出文件名会移除路径字符和不可见字符、避免空名称与重复扩展名，并保留合法中文。

## 预览与渲染

PDF.js 及其 Worker 由构建系统打包并从本站加载。页面预览使用 Canvas：

- 缩略图与主预览使用不同分辨率；
- 设备像素比设置上限，避免无限放大 Canvas；
- 缩略图按需或分批渲染，不一次并发处理全部页面；
- 单页失败显示页码和错误状态，不影响其他页面；
- 页面离开或任务结束后清理 PDF.js 页面、文档和 Canvas；
- 不执行 PDF 内嵌 JavaScript，不自动打开链接、附件或启动动作。

PDF 转图片按用户选择的页码和比例逐页栅格化。PNG、JPEG 和 WebP 是否能成功编码仍取决于浏览器能力；不支持 WebP 编码时应提示用户改用 PNG 或 JPEG。

## 页面范围

范围解析使用 1 起始页码，并在处理前完成校验：

```text
1-3,5,8-10
```

表示三个输出段；自定义分组：

```text
1-3;4-8;9-12
```

表示三个输出文件。解析器会移除空格，拒绝零、负数、倒序区间、空分组和超过总页数的值。每 N 页拆分只接受大于等于 1 的整数。

## 各工具处理方式

### 合并 PDF

按当前文件顺序逐个载入源文档并复制页面到新文档。少于两个有效 PDF 时不能开始；单个文件解析失败应允许用户移除后继续。

### 拆分与提取

先把用户输入转换为页码分组，再从源 PDF 复制对应页面。一个结果直接下载；多个结果使用 JSZip 在浏览器内打包，ZIP 中的文件按页码顺序命名。

### 整理、删除与旋转

界面只维护轻量页面状态：源页索引、当前位置、旋转角度和删除标记。撤销/重做记录操作而不是复制 PDF 字节。导出时按最终状态复制页面，并把旋转写入 PDF 页面属性；删除操作必须至少保留一页。

### 图片转 PDF

浏览器解码图片并处理常见方向信息，一张图片对应一页。页面尺寸、方向、布局、边距、背景和质量参数只作用于新文档。选择“填满页面”时可能裁切图片边缘；降低质量可能将图片重新编码为 JPEG。

### PDF 转图片

每个选中页面渲染为独立图片。多页结果打包为 ZIP，文件名使用补零页码。转换是栅格化过程，结果不再包含 PDF 原始文字、矢量、表单、批注或链接结构。

### 水印

文字或图片水印按位置、透明度、角度、平铺间距和页面范围写入新 PDF。为正确支持中文、英文、数字和常见符号，中文文字可能先通过 Canvas 生成透明 PNG 再嵌入，因此它不再是可搜索文字。

### 页码

纯数字格式优先使用 PDF 标准字体。含中文的格式可能通过 Canvas 生成透明图像。起始数字、开始页、页面范围、位置和边距在导出前校验。

### 元数据

可以读取并修改 `pdf-lib` 可访问的标题、作者、主题、关键词、创建时间和修改时间等基础字段。导出始终生成新文件。

基础字段清理不等于隐私擦除：XMP 包、附件、批注、表单、嵌入文件、对象增量历史或页面内容中仍可能包含信息。对高敏感文件，应使用经过审计的专用清理工具复核。

## 取消与资源释放

处理任务通过 `AbortController` 请求取消。第三方库中的某个同步步骤可能无法在指令中间立即停止，因此“取消”表示在下一个安全边界停止，不承诺瞬时中断。

无论成功、失败或取消，都应执行：

- 取消未完成的渲染任务；
- 清理并销毁 PDF.js 文档；
- 关闭 `ImageBitmap`；
- 缩小或移除不再使用的 Canvas；
- 清空大型数组和 Blob 引用；
- 下载触发后调用 `URL.revokeObjectURL`；
- 终止不再使用的 Worker。

## 性能边界

站点不设置服务端上传上限，因为不存在上传流程。实际能力取决于设备可用内存、浏览器、文件页数、页面复杂度和输出分辨率。

以下情况只触发警告，不一定直接拒绝：

- 单文件超过 100 MB；
- PDF 超过 500 页；
- 多文件总大小较大；
- 在移动设备处理复杂文档；
- 一次导出大量高分辨率图片。

如果浏览器内存不足，应减少页面数或输出比例，并优先改用桌面浏览器。重新生成的 PDF 可能因图片编码、字体嵌入和对象结构不同而比原文件更大。

## 首期不支持

- 加密或带密码的 PDF；
- PDF 压缩；
- PDF 转 Word；
- OCR；
- PDF 加密与解除密码；
- 密码学数字签名；
- 保证所有异常、损坏或非标准 PDF 均可解析。

不得用上传到服务器或第三方服务的方式补齐这些能力，也不得展示无法完成的入口。
