# 隐私说明

## 简要说明

在线 PDF 处理的文件读取、预览、编辑和导出在当前浏览器中完成。网站不提供文件上传或远程文件代理接口，不把用户选择的 PDF、图片或生成结果发送到服务器。

本文说明的是站点自身的处理边界，不代表浏览器、操作系统、下载目录或用户主动访问的其他服务不会留下记录。

## 本地处理的数据

用户选择的以下内容仅用于当前页面会话：

- PDF 与图片字节；
- 文件名、大小、页数和基础元数据；
- 页面缩略图和预览 Canvas；
- 页码选择、排序、旋转、水印和导出参数；
- 新生成的 PDF、图片和 ZIP Blob。

这些内容保存在页面内存中，不写入 Cookie、`localStorage` 或 IndexedDB。刷新或关闭页面后，网站不会恢复当前文件工作区。

网站不会把文件内容、文件名历史、缩略图、水印文字历史或输出文件写入应用日志或分析事件。

## 可以保存的偏好

为了保持界面体验，站点可以在 `localStorage` 中保存：

- 浅色、深色或跟随系统的主题选择；
- 非敏感界面偏好；
- 最近使用的工具；
- 非敏感的默认处理参数。

这些偏好不包含文件内容、文件名历史、页面图像或输出结果。用户可以通过浏览器的站点数据设置清除它们。

## 服务器可见的信息

打开网站时，浏览器需要请求本站的 HTML、JavaScript、CSS、Worker 和图片等静态资源；打开捐赠页面时，二维码图片会从 `meowv.com` 请求。与普通静态网站一样，相关托管服务器或其网络基础设施可能在访问日志中记录 IP 地址、时间、请求路径、User-Agent 和响应状态。

这些请求不包含用户选择的 PDF、图片、文件名或处理结果。站点不需要账户，也不通过服务端处理文件。

生产环境依赖、PDF.js Worker、字体和核心脚本由本站提供，不从公共 CDN 动态加载。捐赠二维码是唯一从 `meowv.com` 加载的页面图片。

## 捐赠页面

捐赠完全自愿，不解锁任何功能，也不影响 PDF 工具使用。捐赠页面展示的支付宝和微信二维码从 `https://meowv.com/medias/reward/` 加载，不通过支付 SDK 读取文件或处理状态。

用户扫描二维码并在支付应用中继续后，支付行为发生在相应支付服务中，适用该服务的隐私规则。请不要在付款备注中填写文件名、文档内容或其他不必要的敏感信息。

## 外部链接

Footer 包含 `excel.meowv.com` 与 `zt.meowv.com` 的工具链接。只有用户主动点击后浏览器才会访问相应站点；新站点的处理规则以其自身说明为准。PDF 文件不会随链接传递。

## 下载与设备痕迹

网站释放页面持有的临时对象，不代表能够清除浏览器或操作系统的全部痕迹：

- 浏览器可能缓存站点静态资源；
- 浏览器可能记录访问历史和下载记录；
- 用户下载的结果会保留在下载目录或用户选择的位置；
- 操作系统可能使用交换空间、备份或文件索引；
- 页面关闭后，内存何时被系统回收由浏览器和操作系统决定。

处理敏感文件后，用户应自行管理下载结果、浏览器历史、备份和设备访问权限。

## PDF 元数据限制

本站只能查看和修改当前库能够访问的基础元数据字段。清除标题、作者、主题、关键词或日期，不等于清除：

- XMP 元数据；
- 附件和嵌入文件；
- 批注、表单、图层或脚本对象；
- 增量保存历史；
- 页面中肉眼不可见但仍存在的文字或图像信息。

因此本站不会声称可以完成取证级隐私擦除。高敏感文档应使用经过审计的专用工具复核。

## PDF 内嵌内容

预览器不执行 PDF 内嵌 JavaScript，不自动打开外部链接、附件或启动动作。PDF 中的外部链接只有在用户主动操作并看到安全提示后才能访问。

## 用户可以做什么

- 刷新或关闭页面以清空当前工作区；
- 下载完成后删除不再需要的结果文件；
- 在浏览器设置中清理 `pdf.meowv.com` 的站点数据和访问记录；
- 使用浏览器开发者工具的 Network 面板确认文件未上传；
- 对高度敏感的 PDF 额外检查元数据、附件和页面内容。

如果未来引入会改变上述边界的功能，应先更新本说明，并且不得默认把文件发送到服务器或第三方服务。
