# 第三方许可索引

Meowv Office 的核心来源与许可：

- `ranuts/document`：GNU AGPL-3.0，完整文本见 `../LICENSE`。
- OnlyOffice Web Apps 与 SDKJS：保留 `public/web-apps/`、`public/sdkjs/` 中的原始版权 Header 和许可声明。
- Geist：SIL Open Font License，见 `../public/ran-fonts/OFL-LICENSE.txt`。
- Noto、Liberation、DejaVu、Comic Neue：字体文件来自固定上游基线；发布前应按上游清单复核相应开放字体许可。
- `ranui`、`ranuts` 与 npm/pnpm 依赖：精确版本见 `../pnpm-lock.yaml`，许可随各包分发。

公网部署修改后的 AGPL 程序时，必须向用户提供当前部署版本对应源码，不得删除适当法律声明或无担保说明。
