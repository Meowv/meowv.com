# 格式兼容性

## 首发正式支持

| 格式 | 主要覆盖                               | 重点风险                     |
| ---- | -------------------------------------- | ---------------------------- |
| DOCX | 文字、段落、表格、图片、分页           | 字体替换、复杂域、桌面插件   |
| XLSX | 多工作表、公式、样式、合并单元格、图表 | 外部链接、宏、特殊插件       |
| PPTX | 多页、文字、图片、形状、主题           | 字体换行、复杂动画、媒体     |
| CSV  | UTF-8 纯数据编辑与导出                 | 分隔符、编码、换行、样式丢失 |

## 兼容导入

上游可能读取 DOC、XLS、PPT、ODT、ODS、ODP、RTF 和 TXT，但在独立自动化与浏览器回归通过前，
不在产品页面公开承诺。旧二进制格式应默认另存为现代 OOXML 格式。

## 明确不支持

- VBA、宏、ActiveX、嵌入脚本。
- 密码破解、DRM 和受保护文档绕过。
- Microsoft 365 在线服务、插件市场、多人实时协作。
- 与桌面 Office 100% 像素级一致。
