# 隐私边界

- 本地文件内容不上传，不写入 Cookie、日志、远程数据库或分析平台。
- Service Worker 只缓存站点资源，不处理跨域请求，也跳过带 `file`、`src` 的文档请求。
- 静态落地页通过 IndexedDB 临时交接用户选择的文件；编辑器读取后立即删除该记录。
- 主题等非敏感偏好可以保存在 localStorage。
- 用户主动打开远程 URL 时，浏览器直接请求目标地址；本站不代理，目标必须支持 CORS。
- 最近使用与回收站仅在当前设备的 IndexedDB 中保存文件名、格式、大小、打开/保存/删除时间，以及支持浏览器中经用户授权的文件句柄；不保存文件内容或缩略图，可随时清空。回收站只删除站点记录，不会删除电脑中的原始文件。
- 通过 Chromium 文件选择器授权打开的文件，编辑完成后会自动回写原文件；该写入只发生在用户已授权的本地文件句柄上。

浏览器关闭、页面刷新或清除站点数据会删除内存状态和本地缓存。P2 草稿恢复如果实现，必须重新评审
数据留存、清理入口和容量限制。
