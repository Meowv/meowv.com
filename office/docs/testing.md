# 测试策略

## 自动化

- `pnpm tsc`：严格 TypeScript。
- `pnpm lint`：Oxlint 与类型检查。
- `pnpm test`：转换、DOCX ZIP、OnlyOffice 事件、嵌入 API、PWA 路由与工具函数。
- `pnpm test:e2e`：首页、静态资源、嵌入 API与核心浏览器流程。
- `pnpm build`：生成可自行部署的静态产物。

## 四格式手工回归

每种格式都必须执行：打开样本 → 做可识别修改 → 保存 → 关闭 → 重新打开导出文件 → 确认修改存在。

- DOCX：中文、表格、图片、分页。
- XLSX：多工作表、公式、合并单元格、样式和图表。
- PPTX：多页、文字、图片、形状和主题。
- CSV：UTF-8/BOM、引号、逗号、中文和换行；确认只保存纯数据。

还需覆盖损坏、密码、超限、取消、只读、远程 CORS 失败、保存超时和未保存退出。
