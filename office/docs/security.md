# 安全说明

- 只接受 DOCX、XLSX、PPTX、CSV 首发入口；旧二进制格式不公开承诺。
- 远程地址仅允许 `http:` 与 `https:`，拒绝 `javascript:`、`data:`、`file:` 等协议。
- 本地文件超过 30MB 提醒，超过 100MB 默认拒绝，避免明显的内存耗尽风险。
- 不执行 VBA、宏、ActiveX、文档脚本，不破解密码和 DRM。
- iframe 与编辑器资源同源，嵌入 API 消息必须遵循文档约定；部署前需复核允许的父级来源。
- 文件名在保存前清理控制字符和系统非法字符。

OOXML 是 ZIP 容器。当前上游转换器仍需更完整的压缩比与解压后总量检查，因此未知来源文件应谨慎
打开；这项是上线前安全审计的剩余风险。
