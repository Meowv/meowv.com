# 现有 Excel 功能基线

记录日期：2026-08-01。现有 `excel/` 保持不动，并继续作为已上线版本和回滚基线。

## 当前架构

- Vue 3、TypeScript、Vite、Pinia。
- Univer 作为表格编辑器，SheetJS 负责 XLSX/XLS/CSV 转换。
- Dexie/IndexedDB 保存工作簿、设置、历史版本、图片和回收站数据。
- Web Worker 负责导入导出，PWA 提供离线访问。

## 当前能力

- 本地工作簿创建、重命名、复制、删除和恢复。
- 自动保存、历史版本、整库备份与恢复。
- XLSX、XLS、CSV 导入；XLSX、CSV、JSON、MSHEET 导出。
- 图片、打印、主题、设置和隐私提示。
- 静态构建产物由根目录脚本统一汇总。

## Office 新项目的迁移关系

| 旧能力              | `office/` 处理        | 状态                         |
| ------------------- | --------------------- | ---------------------------- |
| XLSX/CSV 打开与编辑 | OnlyOffice + x2t WASM | 已接入                       |
| XLSX/CSV 保存       | 编辑器二进制转原格式  | 已接入，仍需真实样本回归     |
| 本地工作簿库        | 首发不迁移            | 明确不提供云端或浏览器文件库 |
| 自动保存与历史      | 首发不迁移            | P2 可评估本地恢复            |
| Word/PowerPoint     | 新增 DOCX/PPTX        | 已接入                       |
| 主题和 PWA          | 迁移产品体验          | 已接入                       |
| 备份/回收站         | 不迁移                | 与单文档 Office 模式不一致   |

在 Office 四格式保存闭环、浏览器兼容和部署验证全部通过前，不删除、不重写 `excel/`，也不移除其
构建入口。域名切换可通过 Nginx 配置独立回滚。
