# 浏览器兼容性

| 能力              | Chromium        | Firefox    | Safari         |
| ----------------- | --------------- | ---------- | -------------- |
| 打开本地文件      | 支持            | 支持       | 支持           |
| OnlyOffice + WASM | 支持            | 需回归     | 需回归         |
| 系统另存为选择器  | 支持            | 下载回退   | 下载回退       |
| 自动回写原文件    | 已授权后支持    | 不支持     | 不支持         |
| PWA 安装          | 支持            | 取决于平台 | 取决于系统版本 |
| File Handlers     | 支持的 Chromium | 不支持     | 不支持         |

要求 HTTPS 或 localhost。首次完整资源加载后才可离线。移动端适合作为查看和轻量修改入口，不承诺
与桌面浏览器相同的复杂编辑体验。
