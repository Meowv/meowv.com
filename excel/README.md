# 在线 Excel 处理

一款纯前端运行的在线电子表格工具。无需注册登录，工作簿在浏览器本地创建、编辑、
保存和导出，不依赖文件转换服务，也不会把表格内容上传到服务器。

项目优先面向桌面浏览器，使用 Univer 提供类似桌面电子表格的编辑体验，并通过
SheetJS Community Edition（CE）在本地读取常见 Excel 文件。

> 本工具不会将用户的表格数据上传到服务器。工作簿默认保存在当前浏览器的
> IndexedDB 中。清理浏览器数据、更换设备或使用隐私模式可能导致数据丢失，请定期
> 导出备份。

## 主要功能

### 工作簿管理

- 创建空白工作簿和内置“项目预算”示例。
- 展示最近使用的工作簿，支持按名称或原始文件名搜索。
- 支持按最近打开、最近修改、名称和创建时间排序。
- 重命名、复制和导出工作簿。
- 工作簿允许同名；只有连续创建默认名称时会自动生成编号避让。
- 工作簿回收站、恢复、彻底删除和清除全部本地数据。
- 导入完成后展示兼容性报告，不静默隐藏已知的格式降级。

### 表格编辑

- 文本、数字、日期、布尔值、公式和空值等常见单元格内容。
- Univer 提供的复制、剪切、粘贴、撤销、重做、行列操作、Sheet 操作、合并单元格、
  冻结窗格、数字格式、单元格样式和状态栏统计。
- 已接入开源版排序、筛选、数据验证、条件格式、查找替换、备注和绘图预设。
- 本地图片以独立 Blob 资源保存，快照只记录本地资源 ID；刷新后仍可恢复，不会上传。
- 中文界面、公式栏、工作表栏、统计栏、上下文菜单和浅色/深色主题。
- 工作簿名称直接编辑，支持手动保存和 `Cmd/Ctrl + N/O/S/Shift+S`。
- 提供当前 Sheet 或选中区域的 A4 打印设置，可选择方向、页边距、网格线、行列标题和
  缩放到一页宽；单次打印限制为最多 2,000 行、100 列且不超过 50,000 个单元格。
- 编辑页支持拖入 `.xlsx`、`.xls` 或 `.csv`，并可取消正在进行的导入。

具体编辑行为和公式覆盖范围由当前锁定的 Univer `0.25.1` 开源版决定，不等同于完整
Microsoft Excel 功能集。

### 本地保存与恢复

- 工作簿、历史版本、设置和本地资源保存在 IndexedDB。
- 编辑后防抖自动保存，保存任务通过串行队列执行，避免并发覆盖。
- 默认停止编辑 `1.5` 秒后保存，最长等待 `5` 秒；可在设置页调整自动保存间隔。
- 页面进入后台、切换路由、关闭页面或应用更新前会尽力刷新待保存内容。
- 自动版本、手动版本、导入版本和恢复前版本。
- 默认最多保留最近 `20` 个自动版本，自动版本默认每 `5` 分钟生成一次；均可配置。
- 支持查看、恢复和删除历史版本，恢复前会先保留当前内容。
- 工作簿快照损坏时保留原记录，可从历史版本创建新的恢复工作簿，或先导出原始数据。
- 文件导入和整库备份恢复使用 IndexedDB 事务，失败或取消时不会留下半恢复状态。

### 本地文件与备份

- 导入：`.xlsx`、`.xls`、`.csv`。
- 导出：完整工作簿 `.xlsx`、当前 Sheet `.csv`、原始快照 `.json`、应用原生
  `.msheet` 备份。
- 导出 `.xlsx` 前明确提示可能降级的数据验证、条件格式、筛选、图片和高级样式，并推荐
  同时保留 `.msheet`。
- 设置页可导出或导入全部浏览器本地数据。
- 文件解析、标准化和生成在 Web Worker 中执行；成功、失败、超时或取消后会终止
  Worker。
- CSV 使用 UTF-8 BOM，方便 Windows 上的常见桌面表格软件识别中文。
- 默认导入限制为单文件 `50 MB`、最多 `100` 个 Sheet、最多 `2,000,000` 个非空
  单元格，解析超时为 `120` 秒。

### PWA 与响应式界面

- 缓存应用静态资源，首次成功加载后可在支持 Service Worker 的浏览器中离线打开。
- 设置页可启用或关闭离线模式；关闭时会移除当前站点的 Service Worker 和应用缓存，不会
  删除工作簿。
- 新版本使用提示式更新；更新前先请求编辑页保存当前工作簿。
- 显示离线状态和可离线使用提示。
- 小屏幕可查看和进行基础编辑，并提示优先使用桌面端完成复杂操作。

## 技术栈

| 分类       | 技术                                                  |
| ---------- | ----------------------------------------------------- |
| 应用框架   | Vue 3、TypeScript、Composition API、Vue Router、Pinia |

服务端 Excel 转换能力。

## 本地数据存储

Dexie 数据库名为 `MeowvLocalSheets`，当前 schema 版本为 `1`。数据库包含：

| 表            | 内容                                     |
| ------------- | ---------------------------------------- |
| `workbooks`   | 工作簿快照、名称、来源、保存和导出状态   |
| `revisions`   | 自动、手动、导入和恢复前历史版本         |
| `settings`    | 主题、自动保存、历史数量和编辑器显示偏好 |
| `recentFiles` | 最近打开文件的本地元数据                 |
| `assets`      | 工作簿关联的本地 Blob 资源               |
| `trash`       | 回收站索引                               |

“保存到浏览器”和“导出文件”是两件事：

- 保存到浏览器：把最新快照写入当前浏览器的 IndexedDB，不生成文件。
- 导出文件：下载 `.xlsx`、`.csv` 或 `.msheet` 到电脑。

IndexedDB 的容量和持久性由浏览器及操作系统决定。浏览器清理站点数据、隐私模式结束、
存储空间不足、设备损坏或更换设备后，本地工作簿可能无法恢复。重要内容应定期导出
`.msheet` 全量备份和必要的 `.xlsx` 文件。

## 隐私说明

- 工作簿文件使用浏览器 File API 读取，并在当前设备内解析。
- 文件转换、公式计算、自动保存和导出均在浏览器内完成。
- 应用不提供文件上传接口，也不调用第三方 Office 文件转换服务。
- 应用不执行 VBA、ActiveX、宏或工作簿内嵌脚本。
- PWA 首次访问和版本更新仍需从站点加载应用静态资源；这不包含 IndexedDB 中的工作簿
  内容。
- 部署平台可能按其策略记录普通 HTTP 请求元数据，但应用代码不会把单元格内容加入这些
  请求。

## Excel 兼容性

这里的“Excel 兼容”指浏览器内读取和生成常见电子表格文件，不代表 Microsoft Excel
实现，也不保证复杂文件往返转换后完全一致。

| 内容                                      | 当前行为                                                         |
| ----------------------------------------- | ---------------------------------------------------------------- |
| `.xlsx`、`.xls`、`.csv` 导入              | 支持本地解析；密码保护或加密文件不支持                           |
| 单元格值和基础类型                        | 尽力保留                                                         |
| 公式                                      | 保留公式原文；计算结果取决于 Univer 开源公式引擎是否支持对应函数 |
| 合并区域                                  | 支持转换                                                         |
| 行高、列宽、行列隐藏                      | 尽力保留                                                         |
| 数字和日期格式代码                        | 尽力保留                                                         |
| Sheet 名称、顺序和显隐                    | 支持；Very Hidden 会降级为普通隐藏                               |
| 字体、字号、颜色、边框、填充和对齐        | 仅做尽力转换，不保证往返保真                                     |
| 编辑器内插入的本地图片                    | `.msheet` 可完整备份；当前 `.xlsx`/`.json` 不包含独立图片 Blob   |
| 冻结窗格                                  | 仅在 SheetJS CE 暴露相关元数据时尽力转换                         |
| 已有自动筛选范围                          | 当前不会导入，需要在编辑器中重新设置                             |
| 工作簿定义名称                            | 当前标准化模型不保留                                             |
| VBA/宏/ActiveX                            | 不执行；普通 `.xlsx` 导出不会保留 VBA                            |
| 图表、数据透视表、Power Query、外部数据源 | 不保证读取或保留                                                 |
| 复杂条件格式、特殊对象、自定义插件        | 不保证读取或保留                                                 |

SheetJS CE `0.20.3` 对高级样式和部分工作簿元数据的读取/写入能力有限。即使编辑器内
可以设置某项样式，也不能据此推断该样式一定会无损写入 `.xlsx`。处理重要或复杂文件时：

1. 导入后查看兼容性报告。
2. 编辑前保留原文件。
3. 使用 `.msheet` 备份应用内完整数据。
4. 导出 `.xlsx` 后在目标桌面软件中复核关键公式、格式和对象。

本项目不支持 VBA，也不会执行任何宏。

## 已知限制

- 没有账号、云同步、实时协作或跨设备同步；所有数据按浏览器站点隔离。
- 不承诺 Excel 文件格式无损往返，尤其是高级样式、图表、透视表、宏和外部数据。
- 公式兼容范围以 Univer OSS 为准，并非所有 Excel 函数或计算细节都一致。
- 打印会把当前 Sheet 或选中区域转成 DOM 表格并提供基础设置，但尚不支持手动分页、
  页眉页脚、图片对象或所见即所得分页预览。
- 移动端以查看和基础编辑为主，复杂选择、拖拽和工具栏操作建议使用桌面浏览器。
- 大文件即使在 Worker 中解析，仍会受设备内存、IndexedDB 配额和浏览器限制影响。
- JSON 导出是工作簿原始快照，图片仅记录本地资源 ID；需要跨浏览器完整迁移时请使用
  `.msheet`。
- Playwright 用例已编写，但不同浏览器版本下的 Univer 画布坐标交互仍需持续维护。

## 浏览器支持

优先支持：

- Chrome 最新两个主要版本。
- Microsoft Edge 最新两个主要版本。
- Safari 当前主流桌面版本。
- macOS 和 Windows 桌面环境。

近期 Firefox 通常可以运行，但不是当前主要验收目标。PWA 安装入口、持久存储策略、文件
下载和隐私模式行为因浏览器及操作系统而异。旧浏览器、内嵌 WebView 和关闭 IndexedDB
的环境不在支持范围内。

## 常见问题

### 表格内容会上传吗？

不会。工作簿内容在浏览器内解析并写入 IndexedDB；应用没有文件上传或远程转换流程。

### 刷新或关闭页面后内容还在吗？

正常情况下会自动保存并在下次打开时恢复。页面关闭前的保存只能“尽力执行”，浏览器被
强制终止、存储写入失败或站点数据被清理时仍可能丢失，所以重要内容必须导出备份。

### 为什么清理浏览器后工作簿不见了？

工作簿默认只存在当前站点的 IndexedDB 中。清理站点数据会同时删除工作簿、历史版本和
设置。可使用设置页导出的全量 `.msheet` 备份恢复。

### `.xlsx` 和 `.msheet` 应该选哪个？

`.xlsx` 适合与常见桌面表格软件交换基础表格内容；`.msheet` 是本应用原生备份格式，更
适合保留本地工作簿、历史版本、资源和设置。重要工作建议两种格式都保留。

### 为什么导入后的样式或对象与原文件不同？

本项目使用 SheetJS CE。它适合基础数据和常见表格结构，但不保证高级样式、图表、透视表、
宏等对象完整往返。导入后可在兼容性报告中查看具体降级项。

### 可以打开带密码或宏的工作簿吗？

密码保护或加密文件不支持。可能检测到宏数据，但应用不会执行宏，导出为普通 `.xlsx`
时也不会保留 VBA。

### 可以离线使用吗？

首次在线成功加载并完成静态资源缓存后，可以在支持 Service Worker 的浏览器中离线打开
应用和已有本地工作簿。首次访问、缓存被清理或加载新版本时仍需要网络。

### 大文件为什么仍然较慢？

Worker 可以避免解析时长时间阻塞界面，但完整工作簿仍需占用当前设备的内存和本地存储。
建议拆分超大文件，并在导入前关闭其他高内存页面。
